# DeskAgent

让 Agent 看懂你的桌面，然后把它重新摆好。

Windows 桌面图标整理工具。扫描桌面上的快捷方式与文件，由 Agent 判断每个图标的归属，重构成有语义分区的桌面空间——游戏一块、开发一块、影音一块，每个区域是一个可拖动的收纳盒。

## 核心设计

**布局与移动分开呈现。** 布局只改 Shell 图标坐标，文件零改动、秒级回滚；移动才动文件系统，需逐条确认。用户永远知道自己即将失去什么控制权。

**LLM 只做判断，不做动作。** Agent 输出分类方案 JSON，所有动作由确定性代码执行：校验 → 快照 → 执行 → 记录。幻觉最多导致分类不准，不会导致文件丢失。

**收纳盒默认是视觉容器。** 图标被框在区域内，文件一个都不动。可升级为物理收纳。

**能力做成 MCP。** 扫描、提案、执行全部暴露为标准 MCP 工具，任何 Agent 都能接管。

## 技术栈

Rust + Tauri 2。

```
crates/shell-win   Windows Shell COM 封装（唯一 unsafe 集中区）
crates/core        采集 / 分类 / 布局 / 执行，无 UI 依赖
crates/storage     SQLite 持久化
crates/mcp         MCP Server
crates/app         Tauri 2 桌面应用
```
